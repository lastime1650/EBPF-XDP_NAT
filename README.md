
# eBPF / XDP 기반 고속 포워딩 프로그램

본 프로그램은 **eBPF/XDP 기반**으로 동작하며, **최소 2개 이상의 네트워크 인터페이스를 가진 환경**에서 인터넷 포워딩이 가능하도록 설계되었습니다.

## 목적

이 레포지토리의 핵심 목적은 다음과 같습니다.

* eBPF `tc_filter`
* `iptables`, `firewalld`, `ufw` 등
  **커널·유저모드 공간에서 발생하는 느린 패킷 처리 경로를 사용하지 않고**

NIC에 가장 가까운 **XDP (eXpress Data Path)** 영역에서 직접 패킷을 처리하여
**초고속 FORWARDING** 을 구현하는 것입니다.

## 이를 통해 증명하는 사항

1. **TC FILTER에서 발생하는 skb 생성 지연 없음**
2. **iptables / firewalld 불필요** (NAT 설정 시 포함)
3. **NIC 이후, 커널 최상단 위치에서 즉시 포워딩**

   * 유저모드
   * tc-filter 이하 공간
     → 일절 간섭 없음
4. **매우 빠른 패킷 포워딩 성능**

## 활용 가능 기능

* XDP 기반 **고속 로깅**
* XDP 기반 **고속 차단 (Drop)**
* 유저모드와 공유되는 **HASH_MAP 활용**

## Important ⚠️

> 누구나 알고 있듯, **간섭을 최소화하는 것이 가장 중요합니다.**
>
> 포워딩에서는 **성능이 최우선**입니다.

### 금지되어야 할 동작 방식

다음과 같은 구조는 **심각한 지연을 유발**하므로 사용하지 않아야 합니다.

1. **XDP → User Space 데이터 전송**
2. **User Space 처리 후 MAP을 통한 응답 반환**

이러한 경우,
XDP를 **초기에 attach 하는 단계에서 필요한 MAP을 미리 준비**하는 방식이
가장 이상적이고 권장되는 구조입니다.
